# آبی‌بی — قالب چندصفحه‌ای سفارش غذا و باشگاه مشتریان

قالب فارسی و راست‌چین با HTML مستقل، Bootstrap 5.3.8 RTL و JavaScript بدون فریم‌ورک. تمام دارایی‌ها محلی هستند؛ نیازی به CDN، Angular، بک‌اند یا build ندارد.

## اجرا

```sh
python -m http.server 8080 --directory dist
```

مرورگر: http://localhost:8080/index.html

برای هاست، محتوای `dist` را در ریشه سایت قرار دهید. برای رفتار یکسان localStorage بین صفحات، اجرای HTTP پیشنهاد می‌شود.

## ساختار

```text
dist/
  index.html                  # فقط اسپلش
  branches.html               # انتخاب شعبه
  home.html                   # خانه، اسلایدر و پیشنهادها
  menu.html                   # منو و جست‌وجو
  product.html?id=1            # جزئیات غذا
  cart.html                   # سبد
  checkout.html               # تکمیل سفارش
  success.html?id=...          # رسید
  login.html                  # ورود نمایشی
  dashboard.html              # داشبورد حساب
  club.html                   # داشبورد باشگاه
  levels.html                 # سطح و پیشرفت عضویت
  points.html                 # گردش امتیاز
  rewards.html                # دریافت پاداش
  coupons.html                # کوپن‌ها
  orders.html                 # سفارش‌ها
  order-detail.html?id=...     # جزئیات سفارش
  addresses.html              # افزودن، ویرایش، حذف آدرس
  favorites.html              # علاقه‌مندی‌ها
  profile.html                # اطلاعات حساب
  assets/
    js/
      data.js                 # محصولات، شعبه‌ها و قوانین نمونه باشگاه
      core.js                 # ابزارهای مشترک و وضعیت محلی
      pages/                  # کنترلر جدا برای هر حوزه
    css/style-02.css
    image/
    fonts/
    vendor/bootstrap/         # CSS RTL و JS محلی Bootstrap
licenses/
```

هر صفحه فایل HTML و آدرس مستقل دارد؛ ناوبری با لینک معمولی انجام می‌شود. index.html مسیریاب یا ظرف سایر صفحات نیست. محتوای ساختاری هر صفحه داخل همان فایل است؛ JS فقط داده‌ها و تعاملات مربوط به آن صفحه را تکمیل می‌کند.

## باشگاه مشتریان

اعداد و مزایا صرفاً نمونه‌اند و در `assets/js/data.js` تغییر می‌کنند:

| سطح | حداقل امتیاز تجمعی سطح |
|---|---:|
| برنزی | ۰ |
| نقره‌ای | ۱۰۰۰ |
| طلایی | ۲۵۰۰ |
| الماسی | ۵۰۰۰ |

حساب نمایشی با ۱۲۵۰ امتیاز قابل خرج و ۱۸۵۰ امتیاز سطح شروع می‌شود: عضو نقره‌ای، ۶۵۰ امتیاز تا طلایی. خرج امتیاز برای پاداش باعث کاهش امتیاز سطح نمی‌شود. دریافت پاداش موجودی را کم می‌کند و تراکنش و کوپن نمایشی می‌سازد؛ هر پاداش یک بار قابل دریافت است. سفارش آزمایشی امتیاز واقعی یا خودکار تولید نمی‌کند؛ فرمول امتیازدهی خرید باید بعداً مشخص شود.

## Bootstrap و دسترس‌پذیری

ساختار container → row → col با breakpoint استاندارد؛ نسخه RTL، Carousel، Accordion، Toast، فرم‌ها، جدول responsive و progress با aria. کلاس row برای چیدمان سفارشی بازتعریف نشده است. اسپلش و اسلایدر تنظیم کاهش حرکت دستگاه را رعایت می‌کنند.

## محدودیت‌ها و نگهداری داده

این پروژه قالب ارائه به مشتری است. پرداخت، پیامک، احراز هویت واقعی، موجودی، ارسال به شعبه و اتصال باشگاه به سرور ندارد. منوی شعبه‌ها مشترک و برخی قیمت‌های افزودنی، هزینه ارسال، رتبه‌بندی پرفروش‌ها و تمام مزایای باشگاه نمونه‌اند.

سبد، پروفایل، آدرس‌ها، سفارش‌های آزمایشی، علاقه‌مندی‌ها و باشگاه در کلید `abibi-ui-v3` از localStorage ذخیره می‌شوند. پیش‌نویس تسویه در sessionStorage است. هیچ‌کدام برای تصمیم مالی/اعتباری امن نیستند و در نسخه واقعی باید سمت سرور اعتبارسنجی شوند. فرم ورود با کد نمایشی 1234 صرفاً مسیر UI را نشان می‌دهد.

برای بازنشانی نسخه نمایشی، در کنسول مرورگر اجرا کنید:

```js
localStorage.removeItem('abibi-ui-v3');
sessionStorage.removeItem('abibi-checkout-v3');
location.reload();
```

## دارایی‌ها

لوگو و ۸ تصویر غذا متعلق به سایت آبی‌بی و برای همین پروژه استفاده شده‌اند؛ مجوز عمومی استفاده در سایر پروژه‌ها ارائه نشده است. Vazirmatn تحت SIL OFL و Bootstrap تحت MIT هستند؛ مجوزها در پوشه `licenses` قرار دارند.

نسخه GitHub از میزبانی قبلی Sites مستقل است؛ این تغییرات برای اجرای مستقیم از همین ریپو تهیه شده‌اند.

## بررسی‌ها

```sh
python scripts/check_structure.py
```

بررسی لینک‌های محلی، فایل‌های دارایی و متادیتای RTL در ۲۰ صفحه انجام می‌شود. در توسعه، همه کنترلرها در محیط DOM آزمایشی اجرا شدند؛ سبد بین صفحات، محاسبه افزودنی، شماره فارسی، ثبت رسید، کسر امتیاز، جلوگیری از دریافت تکراری/کسری موجودی، ثابت‌ماندن سطح، ذخیره کوپن، ویرایش آدرس و سفارش مجدد بررسی شدند. این تست‌ها جای بررسی بصری موبایل و مرورگر واقعی را نمی‌گیرند.
