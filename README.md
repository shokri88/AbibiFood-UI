# آبی‌بی — قالب وب‌اپ سفارش غذا

قالب فارسی و راست‌چین، با اولویت موبایل و چیدمان دسکتاپ. HTML، CSS و JavaScript خالص؛ بدون وابستگی به Angular، بک‌اند یا مرحله build.

## اجرا

فایل `dist/index.html` را باز کنید، یا از ریشه پروژه اجرا کنید:

```sh
python -m http.server 8080 --directory dist
```

سپس به `http://localhost:8080` بروید. برای هاست استاتیک، محتوای پوشه `dist` را در ریشه وب قرار دهید.

## صفحات و امکانات

- اسپلش با انیمیشن لوگو و انتخاب شعبه
- خانه با اسلایدر مستطیلی، دسته‌بندی، پیشنهاد ویژه و پرفروش‌ترین‌ها
- منو با جست‌وجوی فارسی و پنل جزئیات غذا
- سبد خرید، افزودنی و توضیحات غذا
- تکمیل سفارش با ارسال یا تحویل حضوری و زمان دلخواه
- رسید نمایشی، پیگیری و سفارش مجدد
- علاقه‌مندی‌ها و فرم نمایشی ورود

## ساختار

- `dist/index.html`: ورودی برنامه
- `dist/assets/app.js`: داده‌های نمونه، مسیریابی و منطق رابط
- `dist/assets/style.css`: استایل‌ها و قواعد واکنش‌گرا
- `dist/assets/`: لوگو، تصاویر اصلی منوی آبی‌بی و فونت محلی

## محدوده نسخه نمایشی

پرداخت، پیامک، احراز هویت، موجودی و ارسال به شعبه پیاده‌سازی نشده‌اند. منوی شعبه‌ها مشترک است؛ چینش پرفروش‌ها و پیشنهادها، زمان تحویل، هزینه ارسال و افزودنی‌ها نمایشی هستند. قیمت‌ها از منوی مشاهده‌شده کپی شده‌اند و برای فروش واقعی باید به بک‌اند متصل شوند.

سبد و آخرین رسید در `sessionStorage`، علاقه‌مندی‌ها در `localStorage` و پیش‌نویس فرم در حافظه همان صفحه نگهداری می‌شوند. اطلاعات فرم به سروری ارسال نمی‌شود.

منطق سبد، مبلغ افزودنی، جست‌وجوی فارسی، نمایش صفحات و سفارش مجدد بررسی شده است. بازبینی بصری و آزمون روی دستگاه‌های واقعی همچنان لازم است.

## دارایی‌ها

لوگو و عکس‌های غذا از سایت آبی‌بی (`abibifood.app`) و فایل‌های عمومی منوی آن دریافت شده‌اند و برای همین پروژه استفاده می‌شوند؛ مجوز عمومی بازنشر برای سایر پروژه‌ها ارائه نشده است. فونت Vazirmatn تحت SIL Open Font License عرضه می‌شود؛ متن مجوز در `licenses/OFL-Vazirmatn.txt` است.

تنظیمات اختصاصی میزبانی ChatGPT Sites و تاریخچه داخلی انتشار به این ریپو منتقل نشده‌اند؛ تمام فایل‌های لازم برای اجرا مستقل هستند.
